Qianliyan (千里眼)

A Lightweight, Blazing-Fast Native Database Client

Zero Electron bloat. Powered by a high-performance Zig core engine with a modern native SwiftUI interface on macOS, and a 100% client-side WebAssembly in-browser viewer.

Dual-Target Architecture

The core SQLite engine, type serialization, and connection pool are implemented in pure Zig. The macOS desktop app communicates via native C-ABI, while the web viewer runs the identical core compiled to WebAssembly (WASI). 

macOS GUI (SwiftUI) ──[C-ABI]─┐
                              ├──> Zig Core (stdgo.database.sql) ────> SQLite Engine
Web Browser (HTML/JS) ─[Wasm]─┘

Key Features

Native macOS Performance

Pure SwiftUI interface. Sub-second startup, low memory footprint, system dark mode integration, and zero Electron bloat.

100% Client-Side Privacy

The Web viewer executes entirely inside browser Wasm memory with zero cloud uploads. The macOS app accesses files directly with zero telemetry.

Multi-Tab SQL Editor

Multiple concurrent query tabs, sub-millisecond execution metrics, query history tracking, and thread-safe cancellation (⌘.).

Schema & DDL Inspector

Hierarchical schema navigation for tables, column types, primary/foreign keys, and indexes, with one-click inspection of raw CREATE TABLE DDL.

Smooth Grid & Export

Fast two-way scrollable table with adaptive column sizing, cell and row copying, and instant export of query results to CSV or formatted JSON.

Instant Sample Database

Spin up an in-memory e-commerce database with one click. Test schema browsing, complex multi-table JOINs, and query metrics with zero setup.
