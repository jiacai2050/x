macOS 原生客户端 + 浏览器端 WebAssembly · 双端同源

Qianliyan (千里眼)

现代原生轻量级 SQLite 数据库客户端

摒弃 Electron 的沉重负担。基于 Zig 高性能核心引擎打造，原生集成 macOS SwiftUI 界面，同时提供 100% 在浏览器客户端私密运行的 WebAssembly 在线版本。

macOS 预编译安装包即将提供！

目前正在完善 GitHub Actions Release 自动分发流程。如果您拥有 macOS 开发环境，可克隆代码并执行 make dist 本地一键打包 DMG。

双端同源架构设计

核心 SQLite 驱动与连接管理由 Zig 纯静态实现；SwiftUI 桌面端通过高性能 C-ABI 直调，Web 端直接编译为 WebAssembly 运行于浏览器环境。 

macOS GUI (SwiftUI) ──[C-ABI]─┐
                              ├──> Zig Core (stdgo.database.sql) ────> SQLite Engine
Web Browser (HTML/JS) ─[Wasm]─┘

核心特性

原生 macOS 体验

纯 SwiftUI 编写，毫秒级冷启动，超低内存占用，深度集成 macOS 原生明暗主题与快捷键支持，无 Electron 臃肿。

100% 客户端隐私安全

在线版数据库完全在浏览器 WASM 内存沙箱中执行，零网络上传；macOS 端直接读写本地文件，无遥测、无数据回传。

多标签 SQL 编辑与查询

支持多个工作标签页并行执行、毫秒级耗时监控、执行历史溯源，以及针对耗时查询的安全异步中断 (⌘.)。

表结构与 DDL 审查

层次化表导航面板，即时查阅字段类型、主键、外键约束、索引关联以及原始 CREATE TABLE DDL 语句。

流畅表格与数据导出

支持快速二维滚动的数据网格、自适应列宽、单行与多单元格复制，并支持将当前查询结果导出为 CSV 或格式化 JSON 文件。

内嵌 Sample DB 一键上手

无论是开发测试还是在线体验，均可一键通过内存模拟生成电商示例数据库，秒级体验复杂的 Schema 和多表关联查询。

本地编译与开发

git clone https://github.com/jiacai2050/my-works.git
cd my-works/qianliyan

make test    # 运行 Zig 核心单元测试
make macos   # 编译 macOS 原生应用
make run     # 启动 macOS GUI 客户端
make web     # 本地启动 WebAssembly 客户端 (http://localhost:8000)
make dist    # 一键打包 macOS Release DMG (dist/Qianliyan.dmg)
